Survolez un message précédent ou utilisez la ligne d’actions sous la dernière réponse,
puis cliquez sur l’icône de traduction.
La carte sous le message affiche la langue détectée et la traduction ; le bouton de fermeture la masque.

L’icône apparaît sur les messages finalisés contenant du texte.
Une réponse en cours de streaming la reçoit une fois terminée.

La traduction est demandée dans le navigateur directement à `translate.googleapis.com`.
Un clic envoie le texte de ce message à Google ; rien n’est envoyé avant.
La traduction s’affiche en texte brut : la mise en forme Markdown reste sous forme de symboles.
