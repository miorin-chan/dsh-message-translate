Fahre mit der Maus über eine frühere Nachricht oder nutze die Aktionszeile unter der letzten
Antwort und klicke auf das Übersetzen-Symbol.
Die Karte unter der Nachricht zeigt die erkannte Sprache und die Übersetzung;
über die Schließen-Schaltfläche blendest du sie aus.

Das Symbol erscheint an abgeschlossenen Nachrichten mit Text.
Eine noch streamende Antwort erhält es, sobald sie abgeschlossen ist.

Die Übersetzung wird im Browser direkt bei `translate.googleapis.com` angefragt.
Ein Klick sendet den Text dieser Nachricht an Google; vorher wird nichts gesendet.
Die Übersetzung erscheint als reiner Text, Markdown-Formatierung bleibt als Zeichen erhalten.

[Einrichtung und Grenzen](https://github.com/miorin-chan/dsh-message-translate#readme)
